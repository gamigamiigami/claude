# 📌 付箋TODO

Windowsの「付箋」風のシンプルなTODOアプリです。
Electron製のデスクトップアプリなので、**ウィンドウを閉じてもタスクトレイに常駐し、通知時間になると他のウィンドウより前面にリマインドポップアップが画面右上に表示されます。**

## 機能

- タスクの登録: タスク名・期限・提出先・通知の有無・通知時間・紐付けURL
- 完了ボタン(打ち消し線で残る) / 削除ボタン
- 通知タイプ: 🔔 音あり / 🔕 音なし(表示のみ)
- 通知時間になると、アプリを最小化していても・他のアプリが最前面でも、画面右上に最前面ポップアップでリマインド
- ポップアップから「完了にする」「あとで(10分後に再通知)」が可能
- 期限切れタスクは付箋がオレンジ色に変わる
- URLはクリックでブラウザが開く
- データは自動保存(再起動しても残る)

## 動かし方

[Node.js](https://nodejs.org/ja)(LTS版)をインストールした上で、このフォルダで:

```
npm install
npm start
```

## 使い方のポイント

- ウィンドウの「×」で閉じてもアプリは終了せず、タスクトレイ(画面右下の通知領域)に常駐します。リマインドを受け取るにはこのままにしてください。
- 完全に終了するには、タスクトレイの付箋アイコンを右クリック →「終了」。
- タスクデータは OS のユーザーデータフォルダ(`tasks.json`)に保存されます。
